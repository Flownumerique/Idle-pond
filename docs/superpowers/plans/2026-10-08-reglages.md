# Réglages — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** un menu Réglages (son, affichage, jeu, accessibilité) et trois formats d'interface — téléphone, tablette, PC — détectés automatiquement et forçables.

**Architecture:** des types purs (`Reglages`, `Son`, `Adaptation`) testés sans moteur ; un `MagasinDeReglages` qui lit/écrit `reglages.json` et notifie ; la `Boucle` le possède comme elle possède la partie ; `RacineDeLInterface` applique (classes CSS, échelle du panneau, plein écran, fps) ; un tiroir Réglages ouvert par une roue dentée dans la barre.

**Tech Stack:** Unity 6000.6.3f1, C# 9, UI Toolkit, Newtonsoft.Json, NUnit (Unity Test Framework).

**Spec:** `docs/superpowers/specs/2026-10-08-reglages-design.md`

## Global Constraints

- Tout texte affiché vit dans `Textes.Ecran` (`Assets/IdlePond/Noyau/Donnees/Textes.cs`).
- Aucun style dans le C# : classes seulement, styles dans `Mare.uss` / `Theme.uss`.
- `Reglages.cs` et `Son.cs` : ni `UnityEngine` ni `UnityEditor` (règle ajoutée à `ArchitectureTests`).
- Le dossier des fichiers est injecté : `Application.persistentDataPath` n'est lu que dans `Boucle`, et la redirection des ateliers/tests (`ServicesDePartie.RedirigerLaSauvegarde`) vaut aussi pour `reglages.json`.
- Écritures de fichier : temporaire puis remplacement, UTF-8 sans BOM.
- Tests : `outils/unity.sh tests EditMode [filtre]` et `outils/unity.sh tests PlayMode` (éditeur fermé).
- Commits en français, préfixe conventionnel, terminés par les lignes d'attribution de la session.

## Review Focus

1. Un `reglages.json` écrit par une version future ou à la main (valeurs hors bornes, types faux) → défauts champ par champ, jamais d'exception — tests dans la tâche 1.
2. La modification de `PanelSettings` à l'exécution dans l'éditeur modifie l'ASSET → la résolution de référence est remise à l'arrêt (`OnDisable`) — vérifié tâche 7.
3. Réinitialiser sans sauvegarde existante sur le disque (première session) → pas d'exception, pas de copie — test tâche 5.
4. Annonces masquées pendant qu'une rafale de succès arrive → aucune ne ressurgit à la réactivation — tâche 7.
5. Notation changée → tous les nombres déjà affichés se réécrivent sans attendre le tick suivant — tâche 7.
